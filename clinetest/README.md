# PutkiPro - Putkityöyrityksen Verkkosivusto

Tämä projekti oli paikallisen AI agentin testausta Cline sovelluksella.

## Projekti

React + TypeScript + Vite -pohjainen verkkosivusto fiktiiviselle suomalaiselle putkityöyritykselle "PutkiPro".

## Käytetyt Teknologiat

- React 19
- TypeScript
- Vite 8
- CSS (ilman ulkoisia kirjastoja)

## Käyttö

```bash
npm install
npm run dev
```

## Huom

Tämä projekti luotiin kokonaan Cline AI agentin avulla paikallisessa kehitysympäristössä testaustarkoituksessa.
